# 라벨 인코딩 확정 (Phase 0 블로커 해소)

**결론: 제출 라벨 `Answer[i]` = "입력 프레임 i가 시간순으로 몇 번째인가" (입력 위치 → 시간 순위).**

## 근거

### 1차 근거 — 공식 규칙 문서의 예시 (확정적)

대회 규칙 "1. 데이터셋 개요"의 예시: **원본 a,b,c,d / 뒤섞인 입력 a,d,b,c → 정답 `[1,4,2,3]`**.

- 입력 1번(a)=원본 1번째, 입력 2번(d)=원본 4번째, 입력 3번(b)=원본 2번째, 입력 4번(c)=원본 3번째 → rank 인코딩과 일치.
- 반대 해석(시간순 나열: "시간순 k번째가 입력 몇 번인가")이라면 `[1,3,4,2]`가 되어야 하므로 불일치.
- `[1,4,2,3]`은 self-inverse가 아니어서(역순열 `[1,3,4,2]`) 방향을 유일하게 결정한다.

### 2차 근거 — baseline 변환 코드

주최 측 baseline 노트북(`SNU_AI_Challenge_Baseline_Code.ipynb`)의 `parse_model_output` 함수가 같은 방향을 보여준다:

```python
# 모델은 "시간순으로 나열한 이미지 번호"를 출력 (예: [4, 2, 1, 3] = 4번 이미지가 가장 먼저)
# 이를 제출 형식으로 변환:
submission_answer = [0] * 4
for index, image_num in enumerate(result):
    submission_answer[image_num - 1] = index + 1
# [4, 2, 1, 3] → [3, 2, 4, 1]
```

즉 두 표현은 서로 역순열 관계다:

| 표현 | 의미 | 예시 |
|---|---|---|
| 모델 내부 표현 (시간순 나열) | `order[k]` = 시간순 k번째인 입력 이미지 번호 | `[4, 2, 1, 3]` |
| **제출 표현 (rank)** | `Answer[i]` = 입력 프레임 i의 시간 순위 | `[3, 2, 4, 1]` |

문제 설명의 예시 `[3,4,1,2]`, `[2,1,4,3]`은 모두 self-inverse 순열이라 방향을 구분할 수 없었으나, baseline 변환 코드로 확정됨.

## 구현 규칙
